How a record is protected

  1. A transfer is saved in Amazon RDS inside one database transaction.
  2. The app writes the same transfer as a JSON file to the S3 backup bucket.
  3. S3 replication copies the file to a separate DR bucket, usually within seconds.
  4. This page compares the database with the DR bucket on every refresh.
  5. If records go missing, one restore command rebuilds them from the DR bucket.
